# AI变量审查：智能精简与流式候选

默认策略依次检查补齐、修正、智能精简、最终复核。清理覆盖现有审查业务域，不扩展到未纳入快照的长期剧情记忆域，也不因历史长度删除记录。

沿用 `<说明>…</说明><命令>…</命令>` 协议。说明中的每行修复/疑点JSON可附带 category、current、expected。增量解析器只读取完整说明行，去重后通知原Modal，原始命令和内部推理不展示。最新内容在用户位于底部时跟随滚动，向上查看时停止跟随。完整响应结束后候选区域撤下，最终以验证、模拟Diff及结果收束页面为准。

审查使用已有SSE/token delta、取消和超时机制。取消、断流、输出截断或协议失败不能生成可应用预览。审查关闭通用自动重试与不确定的跨域重发；忽略stream而直接返回完整JSON的接口使用同一次响应，明确拒绝stream参数的接口保留原有兼容降级。无新增分析请求。

物品清理分为事实清理、数据整理和保留/待确认。事实清理继续走原库存保护。数据整理仅对程序严格识别的零价值、无用途、无关联一次性杂物开放（普通塑料袋、空的一次性包装、已使用的暖宝宝），不是通用低价物品删除白名单。缺少价值/用途信息、装备、任务、纪念赠品、特殊资产或任何当前业务引用均保守保留。预览注明数据整理，必须另勾选确认；Apply会检查会话内记录的确认要求，篡改结果不能跳过。

技艺schema不变。角色/NPC规范化会自动补齐默认技艺，并保留动态技艺；成长仍可通过push创建动态条目。仅允许删除熟练度0、未入门且无额外描述的非默认动态条目，拒绝删除列表、必需子字段、已学或默认技艺。不会按零值清理生命、余额或任务进度。

现有fingerprint、会话结果绑定、模拟、应用前重验、经济/库存、NPC身份与重复结算保护继续有效。大型存档沿用动态token预算，不增加字符硬裁剪。浏览器与单元验证使用本地模拟接口，不产生真实AI费用。

客户更新文案：变量审查新增实时建议展示，更清晰地提示补齐、修正与清理内容；无用杂物和未掌握的可选技艺整理更加谨慎，所有变化仍需预览确认后才生效。

验证记录：变量审查专项260项通过、7项真实存档包用例因缺少本机测试包跳过；完整测试277个文件通过、2个跳过，2325项通过、13项跳过。另有桌面及手机各1项真实HTTP/SSE渐进展示浏览器测试通过，响应结束前候选可见且不能应用。生产构建及差异格式检查通过；全仓类型检查的基线对照见装备核验补充文档。

既有自定义审查策略不会被覆盖；保存过旧策略的玩家可在原设置中恢复默认，以采用新版智能精简策略。对未知用途或不满足程序严格条件的低价值物品，仍保留为待确认项；不以提高清理数量为目标放松资产保护。

原有浏览器回归16项全部通过，加上新增真实流式2项，共18项通过；覆盖桌面/手机、day/ink主题、预览应用、设置切换、容量及IndexedDB清理保护。所有验证仅在本地执行，本轮改动位于 `feat/variable-review-streaming` 分支（PR #107），未部署。
