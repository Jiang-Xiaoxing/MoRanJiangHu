# 自然文风修复：精简重构说明（未发布）

## 产品界面

PC：设置 → 游戏设定。移动端：设置 → 游戏。自然文风修复位于“防抢话（NoControl）”下方、“COT伪装历史消息注入”上方。

复用既有 `GameSettings` 和 `ToggleSwitch`，使用与相邻“防抢话”“COT伪装历史消息注入”一致的卡片背景、边框、内边距、青色小标题和右侧开关对齐，只保留标题、说明与开关：

> 自然文风修复　[开关]
>
> 减少 AI 正文中的套路化表达、重复句式、冗余修辞和机械化描写。

默认关闭，没有模式、模型说明、提示词编辑器、恢复默认按钮或隐藏高级入口。不再使用独立面板或专用样式。仅在读取/保存失败时显示简短错误，避免无提示地覆盖已有配置；保存失败回退开关，可再次切换重试。

## 统一规则与请求接入

`prompts/writing/naturalProse.ts` 只保留 `DEFAULT_NATURAL_PROSE_PROMPT`，由原三套规则去重整理。重点覆盖词汇口癖、公式化否定转折、三连排比、断裂短句、冗余修饰、固定动作、重复比喻、强行抒情、情绪复述、结尾机械升华及历史口癖复制，同时保留篇幅、细节、心理描写和文学修辞。没有改写原有文风设置。

`utils/naturalProse.ts` 只规范化开关、返回统一规则，不接受 model ID，不读取模型 metadata，也不组合专项规则。

`hooks/useGame/sendWorkflow.ts` 和 `openingStoryWorkflow.ts` 保留每轮配置快照。`services/ai/storyTasks.ts` 的 `generateStoryResponse` 在普通组包和 `orderedMessages` 两条路径进入底层请求前添加同一套 system 提示词：

- 关闭：不添加或修改任何消息。
- 开启：注入统一常量，已存在完全相同的规则消息时不重复添加。
- 保留原始消息和末尾 assistant prefix/prefill。
- 本轮自动重试沿用启动快照；中途切换开关在下一次生成生效。
- 重新生成沿用原有回档、恢复输入、再次发送流程，继续走相同正文入口。
- 不增加 AI 请求，不进行生成后词汇替换；不改变响应解析器。

独立变量生成、变量审查、世界演变等 AI 任务没有接入文风规则。角色、世界观、事实、玩家自主权及 JSON/XML/Tavern Commands 协议由原逻辑保持。

## 持久化与兼容

继续使用 `WuxiaGameDB.settings` 的 `natural_prose_settings` 记录，最终只存：

```json
{ "enabled": false }
```

旧对象中的合法 `enabled` 值保留；`mode`、`generalPrompt`、`claudePrompt`、`geminiPrompt` 及未知字段均忽略。设置服务读取旧记录时写回单开关结构；读、迁移与写串行执行，避免迁移覆盖刚切换的新值。没有合法开关时默认关闭。

`dbService.保存设置` 仅对本功能的设置键进行规范化，保证旧版设置备份导入后也只保存开关。其余设置的图片外置化、API 保留和设置管理机制保持原样。完整设置备份继续包含该记录；启用保留 API 后，文风开关仍可导入，当前 API 不被覆盖。

不修改游戏存档 schema，不把设置写进角色或世界变量。

## 面向玩家的更新说明（未发布）

自然文风修复已简化为一个开关。开启后，所有模型统一减少套路表达、重复句式和冗余修辞，保留正文篇幅与必要细节；设置自动保存，不增加额外 AI 请求。

## 最终统一提示词

```text
【自然文风修复协议】
仅调整正文表达；核心游戏规则、玩家文风与篇幅要求、叙事视角和输出协议优先。不得改变角色性格、世界观、剧情事实、玩家自主权、游戏机制或变量生成/审查逻辑；保持 JSON/XML 结构、标签和 Tavern Commands 格式及变量内容。

1. 减少高频口癖、套话及固定动作模板，如“微微一愣”“眼底闪过一丝”“嘴角勾起”“呼吸一滞”“指节泛白”。优先准确描写实际行为、对话和场景，不让不同人物共用同一套表达。
2. 少用公式化否定转折（“不是……而是……”“没有……只是……”）、连续否定后揭示答案、机械三连排比，以及无意义的断裂短句、破折号和停顿。真正需要对比或节奏变化时才使用。
3. 删减无信息增量的副词、形容词及程度叠加，如“轻轻地”“缓缓地”“几不可察”“近乎虔诚”；用准确动词和恰当细节表达，不堆砌无关的距离、角度和秒数。
4. 避免反复套用涟漪、冰霜、刀锋、羽毛等固定比喻；普通动作不必附加灵魂、信任或重大精神体验等象征意义，不夸大普通情绪。
5. 动作和对白已表达清楚的情绪不再逐句解释；心理描写应提供新信息。避免每回合重复“动作→情绪解释→比喻→哲理总结”的结构，允许场景自然结束，不机械升华、强造悬念。
6. 参考历史正文时保留事实、状态和必要叙事信息，不复制其中反复出现的词汇、句式、动作与比喻模板；不得只换同义词来延续同一口癖。

目标是降低公式化表达的重复频率，保留文学性。自然文风不等于流水账：不得强行缩短正文、删除必要细节，或全面禁止比喻、心理描写及文学修辞。生成前静默检查并直接改善重复和冗余，不输出检查过程。
```
